# 遗迹庭院像素素材

使用内置 imagegen 生成 `frontend/public/terrain/ruins-v2.png`。参考截图中的灰绿石材、残墙、断柱、拱门和破裂地砖，组成可重复使用的图集。

冒险地图以四乘四区块为选址区域，每个区域最多生成一处庭院。庭院占七乘五格，南侧保留三格宽的石板入口。根据地图种子确定选址，避开水面、传送锚点与出生区，保留主通路。石板可以行走，墙体、柱脚和拱门两侧使用与素材位置匹配的碰撞体。
