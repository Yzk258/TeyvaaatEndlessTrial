# 格子地图设计（当前实现）

地图使用32×32世界格子，384×384区块包含12×12格。每格有且只有一种主要素：草地、岸边沙地、水、草丛、树、单块岩石或岩石群。草地作为留白与战斗空间，也属于明确的格子类型。

## 生成顺序与设计理念

1. 从世界种子、全局格子坐标采样平滑噪声，混合大尺度与小尺度水域场，形成有起伏边界的成片湖水。
2. 水域相邻陆格转为沙地，渲染器按邻接方向绘制岸线，避免水直接贴着树或大岩石。
3. 石质区域核心生成连续岩石群，边缘过渡为散石、草地。森林场控制树木出现区域，局部优先级限制相邻树干；草丛场形成连续植被片。
4. 预留贯通世界的宽阔蜿蜒陆路，并在出生点周围160距离留出净空。通道允许可穿行草丛，不生成水或固体，避免大型岩群和湖泊把探索主路截断。
5. 所有采样使用全局坐标和固定盐值，负坐标与区块边界使用相同规则，生成顺序不会改变结果。不再每个区块单独抽随机地标或绘制断开的道路。

## 数据、函数与渲染

MapTile 是主要地形数据，kind 为封闭联合类型；MapChunk 保存格子和由格子派生的碰撞物件。terrainNoise、terrainCellKind、generateChunk 为纯函数，全程使用不可变数组转换。

MapTerrain 先绘制全部地面，再按世界纵坐标绘制树、岩石与草丛，避免后画区块的地面盖住前一区块的树冠。视觉按格子对齐，水与沙地使用像素纹理；岩石群包含石质底色。主界面移动背景也使用同一地图。

## 碰撞与关卡

树干、岩石与岩石群阻挡移动；草丛可穿过。水格使用覆盖整格的圆形安全碰撞体（半径23），岸边有小幅安全余量；目前没有游泳。角色与敌人读取同一份地形障碍。

冒险仍按区块无限生成；关卡保留900×540边界，沿场地外沿留出一圈通路，渲染与碰撞使用相同的格子范围筛选。所有种子都保留出生净空与主要通路，但这并不等于每一处自然地形空隙都能抵达。

## 验证

- node tools/verify-terrain.mjs：5种子、405区块，每格唯一要素、确定性、负坐标与跨块一致、岸线邻接、所有要素覆盖、出生点与主路可站立、水域不可站立、水域连贯性。
- node tools/verify-battle.mjs：实际地图移动、敌人生成与绕障、战斗机制回归。
- npm run build：类型检查与生产构建。

多种子预览：docs/assets/terrain-grid.png；对应可缩放预览为 docs/assets/terrain-grid.html。

## 像素贴图版本（2026-11-09）

地面与物件使用内置 image_gen 生成的 PNG 图集，保存于 frontend/public/terrain/ground-v2.png 与 objects-v2.png。地面包括草地、沙地、水、碎石纹理；透明物件包括树、苔藓岩石、岩石群、草丛。SVG 只负责图集取景与地图排布，原先的几何图形物件已移除。贴图按 pixelated 采样，树木尺寸和水平朝向有确定性变化，草丛略微错位并交叠。

格子从48改为32，区块保持384。每区块144格；水的碰撞半径23、岩石9、岩石群16，通路半宽增至2.2格，保留人物半径12的行走余量。

生成提示词与素材记录见 PIXEL_TERRAIN_ASSETS.md。
