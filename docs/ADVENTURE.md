# 无尽冒险与关卡挑战

## 战斗难度

无尽冒险和关卡挑战共用五档怪物生命倍率。无尽冒险默认选中 20 级。

| 怪物等级 | 普通怪生命（Type 1） | 首领与精英生命（Type 2） |
| --- | --- | --- |
| 20 级 | ×1.00 | ×1.00 |
| 40 级 | ×3.04 | ×3.34 |
| 60 级 | ×9.47 | ×10.41 |
| 80 级 | ×20.97 | ×27.77 |
| 100 级 | ×41.53 | ×65.16 |

## 无尽冒险

地图按区块生成，镜头跟随角色。每 30 秒进入下一波。令 `w = 当前波数 − 1`，新生敌人的生命在难度倍率上再乘 `1 + 0.25w`，伤害按基础伤害乘 `1 + 0.12w`，最后向上取整。已在场的敌人保留出生时的属性。刷怪间隔逐步缩短，每批数量和场上人数有上限。每十波会尝试刷出一只丘丘岩盔王。

角色倒下或主动撤离时，按击杀数和有效战斗时间结算。令 `B` 为完整的 30 秒区间数，`K` 为击杀数。摩拉基础值为 `40B + 10K`，原石基础值为 `3B + 2 × floor(K / 50)`。20 至 100 级分别将这两项乘以 1、2、3、4、5。开场倒计时、暂停、升级选择和掉落回收时间不计入有效进度。未吸收的摩拉粒子也计入总额。每只丘丘岩盔王仍掉落一件圣遗物。

## 关卡挑战

先选择摩拉或原石类别，再点对应的等级卡片开打。每张卡片绑定场地、敌人数和通关奖励。角色沿用开局时的培养等级和装备，本局无经验掉落与升级。击败指定数量的敌人即可领取奖励，可重复挑战。

| 难度 | 地图 | 敌人 | 摩拉关卡 | 原石关卡 |
| --- | --- | ---: | ---: | ---: |
| 20 级 | 低语森林 | 15 | 300 | 40 |
| 40 级 | 风起山谷 | 30 | 600 | 80 |
| 60 级 | 遗迹边境 | 50 | 1000 | 120 |
| 80 级 | 风起山谷 | 60 | 1800 | 180 |
| 100 级 | 遗迹边境 | 75 | 3000 | 260 |

原来的三张关卡卡片对应 20、40 和 60 级，继续使用原关卡 ID 及通关记录。80 和 100 级有独立的通关记录。

## 配置与扩展

- [adventure-rules.json](../shared/adventure-rules.json) 配置共用难度倍率，以及无尽模式的波次、刷怪上限与奖励。开局生成包含难度、装备和地图的快照。
- [Stage.ts](../frontend/src/objects/Stage.ts) 配置分类、关卡 ID、地图 ID、敌人数和通关奖励。新增关卡时，选择已有地图或添加新的地图记录。
- [BattleMap.ts](../frontend/src/objects/BattleMap.ts) 分别登记无尽地图和关卡地图。无尽地图每局使用随机地形种子，关卡地图使用各自的固定种子。渲染、碰撞和水格减速使用同一份地形配置。以后可在地图生成函数接入新的地图数据来源，关卡仍通过地图 ID 引用。
- [TrialReward.ts](../frontend/src/objects/TrialReward.ts) 定义带类型标记的奖励条目。新增道具或装备奖励时，为该类型增加数据字段、展示方式和入库逻辑，然后写入关卡的奖励列表。
- [progression.ts](../frontend/src/game/local/progression.ts) 统一计算和发放试炼奖励。IndexedDB 在一次事务里保存余额、试炼结果和通关状态，并以试炼 ID 防止同一局重复发奖。

## 验证

- `npm run build` 检查类型并构建游戏。
- `node tools/verify-battle.mjs` 检查难度倍率、刷怪、地图边界和战斗计时。
- `node tools/verify-local-save.mjs` 检查两类关卡和无尽冒险的结算、通关记录及重复发奖。
- `node tools/verify-adventure-ui.mjs` 检查难度切换、关卡分类、撤离和继续存档。运行前启动游戏开发服务器。
