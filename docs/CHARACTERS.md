# 角色配置指南

攻击系统已升级：角色额外配置 attackPattern（类型化命中机制）和 attackVisual（表现），现支持投射物、近战扇形、目标范围。实际角色名单以 shared/characters.json 为准；旧版“远程即时命中/近战全范围”描述为历史方案，实际以 [攻击系统说明](ATTACKS.md) 为准。

安柏、芭芭拉、丽莎、凯亚、班尼特和迪卢克的像素立绘由 shared/character-portraits.json 登记。培养页使用半身照，其余角色在培养页使用已保存的参考图占位，在其他页面显示待设计文字。参考图、生成提示词及预览见 [立绘修订](CHARACTER-PORTRAITS.md)。替换外观不需要更改角色数值配置。

角色定义统一保存在 shared/characters.json。前端构建直接读取，后端将同一文件作为资源打包并由 content 服务解码校验。修改后需重启后端，发布时重新构建前端；不是实时在线编辑器。

## 三个独立维度

| 字段 | 合法值 |
| --- | --- |
| element | cryo 冰、anemo 风、pyro 火、electro 雷、hydro 水、dendro 草、geo 岩 |
| weapon | claymore 大剑、sword 单手剑、catalyst 法器、bow 弓箭、polearm 长枪 |
| attackStyle | melee 近战、ranged 远程 |

三者没有派生或绑定关系；例如大剑/远程、法器/近战都是合法组合。元素当前仅作角色分类和展示，不参与反应计算。武器类型目前作为角色配置与界面信息，不自动改变攻击规则。

## 数据字段

- id：唯一且稳定的角色ID，不要修改已有角色ID；玩家所有权用它关联。
- name、title、color、symbol：显示名称、称号、占位配色与符号。
- baseAttack、attackGrowth：1级攻击、每级攻击成长。
- baseHp、hpGrowth：1级生命、每级生命成长。
- attackRange：攻击范围（战场坐标单位）。
- attackIntervalTicks：攻击间隔，每逻辑步50毫秒。例如12为0.6秒。
- maxLevel、levelUpCost：等级上限、每次升级摩拉消耗。
- inStandardBanner：是否加入现有角色卡池；先按稀有度抽取，再在对应类别内等概率选择。rarity 为4／5星，没有三星角色；角色池可产出三／四星武器，完整概率与保底见 [祈愿规则](WISHES.md)。

实际属性公式：基础值 + (等级−1)×每级成长。培养页与开局调用相同的前端纯函数，后端负责验证等级上限、消耗与角色所有权。开局响应和持久幂等回执保存角色定义快照，本局不随配置修改而变化。

## 如何新增角色

在JSON数组中加入完整记录即可，前端名单、属性预览、升级消耗和后端卡池无需逐处添加名字。先配置 inStandardBanner=true 才能通过当前祈愿获取。初始赠送角色仍明确为安柏，不随名单顺序改变。

示例：复制安柏记录，换成新ID和名称，把 weapon 设为 claymore、attackStyle 设为 ranged，即可创建远程大剑角色。无需修改类型枚举或战斗条件分支。若创造新的武器类别或攻击机制，才需要修改类型与执行函数。

## 当前战斗执行范围

melee 每次攻击命中范围内所有敌人；ranged 自动选择范围内最近的一名敌人。射程、冷却和攻击力来自角色配置；远程当前为即时命中，尚未实现飞行箭矢或弹道动画。现有安柏、芭芭拉、丽莎均配置为远程，但属性、范围、攻速和成长可不同。

技能、天赋、元素爆发与元素反应尚未加入。本轮不为它们创建空实现。
