# 全角色展示立绘工作记录

当前 50 位角色均有像素半身展示立绘，供培养、综合、图鉴及祈愿使用。战斗入口使用独立的素材选用方式。

立绘位于 `frontend/public/characters/display/`，由 `shared/character-display-portraits.json` 按从左至右、从上至下的顺序索引。
