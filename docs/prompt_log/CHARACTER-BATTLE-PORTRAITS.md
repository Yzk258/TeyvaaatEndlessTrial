# 全角色战斗像素图工作记录

当前 50 位角色均有 Q 版战斗像素图。以各自的原图作为造型参考，以胡桃的战斗像素图作为比例和画风参考。每位角色按 46×46 游戏单位绘制到战场，并沿用战斗中根据移动距离、朝向和攻击计算的姿态。

战斗素材由 `shared/character-battle-portraits.json` 按从左到右、从上到下的顺序索引。新素材位于 `frontend/public/characters/battle/`，胡桃使用已有的单图。

## 第一页

使用内置 imagegen 绘制 11 位角色，分为 A 至 C 三张图集。
