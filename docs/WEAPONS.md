# 武器机制与配置

## 当前玩法

入口：武器培养（#/weapons）；祈愿页（#/wishes）切换“角色祈愿 / 武器祈愿”。

培养页与角色培养统一布局：顶部左侧展示选中武器大图、星级、等级和装备状态，右侧显示主副词条的升级前后数值、天赋、升级费用和装备／卸下操作；武器列表放在下方。空背包显示未获得预览与祈愿入口，不提供强化或装备操作。宽屏左右排列，窄屏纵向排列。

页面由 SelectedWeapon、WeaponDetails、WeaponInventory 三个区域组成，保留原有升级扣费、武器类型匹配和占用限制。构建及已装备／空背包渲染检查通过，[布局预览](assets/weapon-development-preview.png)。

当前15件武器：原有5件基础武器，加上天空系列5件、西风系列5件，分别覆盖大剑、单手剑、法器、弓箭、长枪。每件拥有主词条、副词条、天赋、成长、等级上限和升级费用。当前20级上限，升一级消耗300摩拉；词条成长固定，不随机洗词条。培养页显示收集进度，未拥有武器灰显，获得后可选择升级与装备。

武器分为三星基础武器、四星西风系列、五星天空系列，各5件。抽取先决定星级，再在同星级内等概率选择；五星基础概率0.7%、四星6%，最多80抽获得五星、10抽获得四星或以上，包含软保底模型。角色祈愿也可获得三／四星武器。两个卡池分别保存四星和五星进度，已移除五抽补缺。重复武器聚合为 copies 数量，暂不提供精炼或多个独立副本。完整规则、改编范围和迁移见 [祈愿规则](WISHES.md)。

每名角色最多装备一件武器，一件武器只能由一名角色装备。装备前校验玩家所有权、角色所有权和武器类型；例如安柏只能装备弓箭，但弓箭本身不强制角色必须远程。同类型角色换用武器需要先从原角色卸下。没有武器也可出战。

## 统一配置

定义在 shared/weapons.json，由游戏读取并校验。发布配置变更时重新构建前端。全部 15 件武器关联 shared/weapon-appearance.json 中的透明底像素图，培养、图鉴、祈愿结果复用同一外观索引。

新增武器数值和天赋是本项目自定义规则，并非原作数值。暂不引入原作的充能、暴击、能量球和额外攻击机制，沿用已有词条与命中天赋模型。

| 字段 | 作用 |
| --- | --- |
| id / name / symbol | 稳定ID、名称、占位图形 |
| weapon | 与角色相同的五种 WeaponType，独立于远近程 |
| rarity | 3／4／5星，决定对应卡池、概率分组和展示 |
| mainStat / subStat | 词条类别、1级值base、每级growth |
| talent | 名称、说明、条件、阈值、伤害增幅百分比 |
| maxLevel / levelUpCost | 等级上限、升级摩拉消耗 |

词条类别为封闭类型：attackFlat、attackPercent、hpFlat、hpPercent、attackSpeedPercent、attackRangeFlat，分别为攻击数值、攻击百分比、生命数值、生命百分比、攻速百分比和范围数值。

词条值 = base + (等级−1)×growth。攻击 = (角色攻击+武器固定攻击)×(1+攻击百分比/100)；生命同理。范围直接相加；攻击间隔 = 四舍五入(原间隔/(1+攻速百分比/100))，至少1个逻辑步。生命取整数，攻击与词条保留两位小数；界面与战斗复用纯函数。

## 天赋

| 条件 | 判定 |
| --- | --- |
| always | 每次命中生效 |
| near | 命中前距离 <= threshold |
| far | 命中前距离 >= threshold |
| reaction | 本次命中确实触发元素反应 |

当前天赋只在满足条件时增加本次伤害百分比，不改变角色状态或触发连锁反应。距离按战场坐标计算，等于阈值也生效。元素反应尚未实现，战斗明确传入 reactionTriggered=false，反应天赋不会误触发。

当前预制：鸦羽弓（远距）、冷刃（近距）、铁影阔剑（常驻）、白缨枪（距离）、魔导绪论（反应条件预留）。近距/远距条件与角色攻击类型无绑定，远程角色贴身命中也可以满足近距天赋。

## 数据与接口归属

- content：WeaponDefinition、词条和天赋封闭类型，公开 ListWeaponsMessage。
- weapons：owned_weapons、weapon_equipment；LevelUpWeaponMessage、EquipWeaponMessage，内部 GetEquippedWeaponMessage。
- wishes：weapon_pity 和 PerformWeaponWishMessage，复用通用持久幂等回执保存抽取结果。
- economy：余额、流水、档案聚合；Profile 增加 weapons、equipment、weaponPity。
- runs：开局调用武器API，将定义与等级加入 RunStart 并保存于该次请求的持久回执。局外升级/换装不会改动已有局内状态。

所有资产写入先锁定用户行，并在同一事务内扣费、成长/发放、修改保底和保存幂等结果。装备表用复合外键校验所有权，用唯一约束限制同一武器同时被多个角色使用。

## 验收

`node tools/verify-local-save.mjs` 检查本地培养、祈愿保底、资源消耗、装备和开局快照。

tools/verify-battle.mjs：词条合成、武器成长、距离阈值边界、反应条件不误触发、天赋进入真实伤害计算，以及原有战斗回归。

尚未实现：精炼、随机词条、暴击词条、天赋等级、限时增益、元素反应和武器独立背包副本。像素图与生成记录见 [武器像素图](WEAPON-PIXELS.md)。
