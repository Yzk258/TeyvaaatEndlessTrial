# 武器机制与配置

## 当前玩法

在武器培养（`#/weapons`）强化武器，在角色培养（`#/characters`）的「武器」栏装备或卸下武器。祈愿页（`#/wishes`）可切换角色祈愿和武器祈愿。

武器培养按武器种类显示数量。左侧可在同种武器的多把副本之间切换，并查看该副本的等级和装备者。右侧分为「强化」和「精炼（建设中）」，强化页显示词条、天赋和升级费用，精炼页暂为空白。

在角色培养选中角色后，切换到「武器」栏可查看当前装备和已拥有的同类型武器。武器被其他角色占用时，先选择该角色并卸下，再为目标角色装备。

当前有 15 件武器，包括基础武器、天空系列和西风系列各 5 件，覆盖大剑、单手剑、法器、弓箭、长枪。每件拥有主词条、副词条、天赋、成长、等级上限和升级费用。当前等级上限为 20，每级消耗 300 摩拉，词条按固定规则成长。武器培养和图鉴将未拥有的武器显示为黑色剪影。

武器分为三星基础武器、四星西风系列、五星天空系列，各 5 件。武器祈愿先决定星级，再在同星级内等概率选择。五星基础概率为 0.7%，四星为 6%，最多 80 抽获得五星，最多 10 抽获得四星或以上。角色祈愿也可获得三星或四星武器。每次抽到武器，背包都会增加一把 1 级武器。 [祈愿规则](WISHES.md)

每名角色最多装备一把武器，每把副本只能由一名角色装备。两名角色可以分别装备同一种武器的不同副本。装备前校验武器、角色的所有权与武器类型。若要转用某一把已装备的武器，先从原角色卸下。没有武器也可出战。

## 统一配置

定义在 shared/weapons.json，由游戏读取并校验。发布配置变更时重新构建前端。全部 15 件武器关联 shared/weapon-appearance.json 中的透明底像素图，培养、图鉴、祈愿结果复用同一外观索引。

新增武器数值和天赋是本项目自定义规则，并非原作数值。暂不引入原作的充能、暴击、能量球和额外攻击机制，沿用已有词条与命中天赋模型。

| 字段 | 作用 |
| --- | --- |
| id / name / symbol | 稳定ID、名称、占位图形 |
| weapon | 与角色相同的五种 WeaponType，独立于远近程 |
| rarity | 3／4／5星，决定对应卡池、概率分组和展示 |
| mainStat / subStat | 词条类别、1级值base、每级growth |
| talent | 名称、说明、条件、阈值、伤害增幅百分比 |
| maxLevel / levelUpCost | 等级上限、升级摩拉消耗 |

词条类别为封闭类型：attackFlat、attackPercent、hpFlat、hpPercent、attackSpeedPercent、attackRangeFlat，分别为攻击数值、攻击百分比、生命数值、生命百分比、攻速百分比和范围数值。

词条值 = base + (等级−1)×growth。攻击 = (角色攻击+武器固定攻击)×(1+攻击百分比/100)；生命同理。范围直接相加；攻击间隔 = 四舍五入(原间隔/(1+攻速百分比/100))，至少1个逻辑步。生命取整数，攻击与词条保留两位小数；界面与战斗复用纯函数。

## 天赋

| 条件 | 判定 |
| --- | --- |
| always | 每次命中生效 |
| near | 命中前距离 <= threshold |
| far | 命中前距离 >= threshold |
| reaction | 本次命中确实触发元素反应 |

当前天赋只在满足条件时增加本次伤害百分比，不改变角色状态或触发连锁反应。距离按战场坐标计算，等于阈值也生效。元素反应尚未实现，战斗明确传入 reactionTriggered=false，反应天赋不会误触发。

当前预制：鸦羽弓（远距）、冷刃（近距）、铁影阔剑（常驻）、白缨枪（距离）、魔导绪论（反应条件预留）。近距/远距条件与角色攻击类型无绑定，远程角色贴身命中也可以满足近距天赋。

## 武器副本与存档

- `Weapon` 定义一个武器种类的词条、天赋与成长。`OwnedWeapon` 记录单把武器的独立 `id`、种类 `weaponId` 和 `level`。
- `Equipment` 记录角色与 `weaponInstanceId` 的关系。强化和装备按副本 ID 更新，开局读取对应副本的定义和等级。
- 第 1 版存档按种类保存 `copies`。读取时会将其转换为第 2 版副本记录，第一把继承原等级和装备关系，其余从 1 级开始。为防止异常旧档在展开时占用过多内存，迁移最多展开 65,536 把。

强化扣费、祈愿发放、保底更新和装备变更在各自的 IndexedDB 事务内保存。局外升级和换装从下次出战生效。

## 验收

`node tools/verify-local-save.mjs` 检查本地培养、祈愿保底、资源消耗、装备和开局快照。

tools/verify-battle.mjs：词条合成、武器成长、距离阈值边界、反应条件不误触发、天赋进入真实伤害计算，以及原有战斗回归。
