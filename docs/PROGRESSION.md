# 角色培养、掉落吸收与随机强化

## 角色培养页面

顶部左右两列分别为选中角色的半身立绘、属性与强化操作，角色列表位于下方。窄屏按相同阅读顺序纵向排列。培养属性仍包含已装备武器，升级前后数值复用实际计算函数。

CharacterPortrait 在培养页使用 bust 取景，优先显示已有像素立绘，其余角色按需加载用户保存在“角色立绘”目录的原图。原图复制至 frontend/public/characters/references/，由 shared/character-references.json 登记，图鉴也可显示。已可玩的新增角色复用本项目相应武器的基础攻击和培养参数。达妮卡与至冬女皇作为资料条目收录在图鉴。战斗仍从像素素材读取，胡桃使用独立的 Q 版素材。

## 掉落与吸收

无尽模式击败怪物后掉落经验和摩拉。关卡挑战掉落通关摩拉进度。经验和摩拉每类最多拆为 3 颗，用整数差分保持总量。青蓝菱形表示经验，金色方粒表示摩拉。粒子先散开，再追踪角色，接触后播放吸收效果。丘丘岩盔王还会掉落一件圣遗物。 [圣遗物掉落](ARTIFACTS.md)

经验只在粒子第一次进入 absorbed 时加入经验条，类型经验仍为史莱姆5、丘丘人12、首领100。经验溢出保留；一次吸收跨多级时按待选次数逐次提供强化。

无尽模式的基础奖励为每个击杀 10 摩拉，每 30 秒有效战斗另计 40 摩拉和 3 原石，每 50 次击杀另计 2 原石。实际发放按所选难度乘以奖励倍率。主动撤离或死亡时按进度结算。关卡挑战将通关摩拉分配到每个敌人的掉落中，清场后一次性发放该关奖励。存档事务会防止重复领取。 [冒险与关卡规则](ADVENTURE.md)

通关或角色倒下后，如还有粒子，则进入 collecting 阶段。停止移动、攻击、刷怪，只完成最后一批掉落吸收与视觉清理，随后显示结束界面。暂停／升级时粒子与攻击一并冻结，结束后的继续结算不重复产生掉落。

## 无尽模式随机三选一

| 选项 | 效果 | 限制 |
| --- | --- | --- |
| 锐意 | 攻击力+1 | 无额外叠加上限 |
| 复苏 | 恢复35生命 | 满生命时不进入候选 |
| 远见 | 攻击范围+20% | 范围判定的伤害半径同步扩大 |
| 疾攻 | 攻击间隔缩短15%，向下取整 | 最短2个逻辑步；已达上限时过滤 |
| 轻步 | 移动速度+15% | 每步最多12单位；已达上限时过滤 |
| 坚韧 | 生命上限+25，同时恢复25生命 | 仅本局 |
| 连击 | 每轮追加一次完整攻击 | 最多追加3次，总计4次；已达上限时过滤 |

选项从当前合法候选中抽取3项，不重复。升级随机种子与敌人生成种子分离；同一状态可复现，界面重绘、暂停和恢复不会重新抽选。每次选中后扣除一次待选次数，多级升级按新属性重新生成下一组选项。未提供的选项不能通过状态动作生效。

追加攻击每隔3步（0.15秒）执行一次，投射物、近战扇形和目标范围都适用。追加攻击进入真正的攻击判定，不递归生成新的追加攻击；目标消失时该次追加取消。暂停或升级时调度冻结。

HUD显示当前攻击、射程、攻速、移速、每轮攻击次数及摩拉吸收进度，升级选项显示真实的前后数值。局内强化在新对局重置，不修改角色培养等级与武器配置。

## 类型与函数归属

- game/objects：LootParticle、UpgradeChoice、BattleState、AttackResolution 定义封闭状态与不可变记录。
- game/functions/battleLoot.ts：整数拆分、粒子运动、仅一次吸收计数；更新复杂度随粒子数线性增长。
- game/functions/battleUpgrades.ts：合法候选、独立随机种子、强化数值的纯函数。
- resolveAttacks：主攻击与延迟追加攻击、判定和命中信息。
- stepBattle：战斗、升级、暂停、收尾与结束的状态转换。
- CharacterPage：选中角色、强化操作、角色列表三个可见业务区域。
- BattlePage：LootParticles、UpgradeOptions消费状态绘制，不修改战斗规则。

画面最多展示最近256组粒子，全部逻辑记录仍推进并计数，不因渲染数量限制丢失经验或摩拉。
