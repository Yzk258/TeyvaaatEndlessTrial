# 圣遗物

每位角色可装备生之花、死之羽、时之沙、空之杯、理之冠各一件。部位名称沿用原神。 [HoYoWiki 圣遗物资料](https://wiki.hoyolab.com/pc/genshin/entry/5579?lang=zh-tw)

| 稀有度 | 强化上限 |
| --- | ---: |
| 白 | +4 |
| 绿 | +8 |
| 蓝 | +12 |
| 紫 | +16 |
| 金 | +20 |

## 初学者套装

初学者是白色套装。新建存档和旧存档首次读取时各获得一套 +0 圣遗物。到「培养 → 圣遗物培养」强化，每级消耗 200 摩拉。到「角色培养 → 圣遗物」按部位装备或卸下，背包可查看持有的圣遗物。

| 部位 | 道具 | +0 主词条 | 每级成长 |
| --- | --- | --- | --- |
| 生之花 | 初学者的野花 | 生命值 +10 | +3 |
| 死之羽 | 初学者的雀羽 | 攻击力 +1 | +0.25 |
| 时之沙 | 初学者的沙漏 | 攻击加成 +4% | +1 个百分点 |
| 空之杯 | 初学者的陶杯 | 攻击范围 +4 | +1 |
| 理之冠 | 初学者的叶冠 | 生命加成 +4% | +1 个百分点 |

- 装备至少两件，攻击力加成 +15%。
- 装备至少四件，每击败一名敌人回复最大生命的 3%，四舍五入为整数，回复受最大生命限制。两件套效果同时生效。

## 图鉴与掉落

圣遗物图鉴显示部位、套装、主词条和持有数量，未获得的条目显示黑色剪影。无尽模式每十波出现的丘丘岩盔王被击败时，固定掉落一件随机部位的初学者圣遗物，等级为 +0。掉落在战场显示图标，主动撤离或战斗结束后随结算发放，即使当时还没吸收也会入包。同一试炼重复结算不会重复发放。

## 配置与存档

- `frontend/src/objects/Artifact.ts` 登记部位、稀有度、主词条、成长与套装效果。配图按圣遗物种类 ID 保存在 `frontend/public/artifacts/`。
- `Profile.artifacts` 保存各副本的等级，`Profile.artifactEquipment` 关联角色与副本 ID。同一副本只能装备给一个角色，同一角色的同一部位最多装备一件。
- 培养预览和战斗开局使用相同的属性计算。开局读取本局圣遗物快照，击杀回血在战斗中按当前最大生命计算。
